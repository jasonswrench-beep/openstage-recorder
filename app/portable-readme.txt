OpenStage Recorder
==================

A light screen recorder for Windows, with a simple editor.

TO START
  Double-click "OpenStage Recorder.exe". There is nothing to install.

  Keep the two .exe files in this folder together. OpenStage Recorder
  finds the recording program (openstage-capture.exe) beside itself.

THE FIRST TIME
  Windows may show a blue box that says "Windows protected your PC". That
  is because this program is not signed yet. Click "More info", then
  "Run anyway".

WHERE YOUR RECORDINGS GO
  Into the recordings folder shown on the Record screen. You can change it
  there. Recordings are never kept inside this program's folder.

TO REMOVE IT
  Close it, then delete this folder. Your recordings stay where they are.

THIS IS A TEST BUILD
  It has been built, but it has not yet been tried on a real computer
  beyond the Record screen. Please tell the project owner what worked and
  what did not.
